Add an `ai` content extraction strategy that uses any OpenAI-compatible vision-language model (OpenAI, Ollama, LM Studio, vLLM, OpenRouter, Mistral, Anthropic, …) to extract document text **and** structured metadata (title, tags, date, custom fields). PDFs are rasterized page-by-page — JPEG by default, with per-model resolution clamps resolved from the endpoint's advertised metadata, a built-in model-family table, or explicit config — and sent in chunks of `pagesPerBatch` pages. Each chunk answers with content + metadata in one call; for multi-chunk PDFs a final metadata-only call reconciles document-wide metadata from the joined transcription. Extracted metadata is applied automatically within guardrails: the document is renamed only while it still carries its original file name, the document date is only filled when unset, tags reuse existing ones (new ones only when allowed), and custom property values go through the same validation as the API. Extraction retries transient failures with backoff, and rendered pages stay memory-bounded per chunk. It reuses the shared AI configuration (`ai.defaultModelId`, plus optional endpoint metadata probing via `AI_PROBE_MODEL_METADATA`) with per-strategy overrides, and AI usage is tracked through the credits system like other AI features.
